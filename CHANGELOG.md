# Release notes

## 1.2.0 (2026-11-27)

- New neon app icon, matching the rest of the Zilla family.
- The **Connections** sidebar can be resized: drag its right edge, or double-click the edge to reset it.
- **About** moved to an information button in the bottom-right of the sidebar. It now has a side-by-side layout with artwork, keyboard shortcuts, update checking and **Release notes**, which you can export as Markdown.

## 1.1.1 (2026-11-27)

- Widened the **About** dialog.

## 1.1.0 (2026-11-27)

- **Winzilla is now FtpZilla.** Installing FtpZilla replaces Winzilla. Saved connections move to `%LOCALAPPDATA%\FtpZilla` automatically on first launch.

## 1.0.9 (2026-11-27)

- Saved connections are organised into coloured groups (Production, Develop and Read-only by default). When connected, the title bar and remote pane show the group's colour and name.
- **Read-only** groups allow browsing and downloading only.
- Connections are stored in `connections.json`, with passwords encrypted by Windows DPAPI.

## 1.0.8 (2026-11-10)

- Case-insensitive filter for the current folder.

## 1.0.7 (2026-11-10)

- Copying remote files puts virtual files on the clipboard, so nothing downloads until you paste.
- The command log can be exported.

## 1.0.6 (2026-11-10)

- Transfers show elapsed time, time left and speed.
- Added a command log, a right-click menu and copy/paste with Explorer.
- Fixed dragging several files out to Explorer at once.

## 1.0.5 (2026-11-09)

- Saved connections, with **Check for updates** in About.

## 1.0.4 (2026-11-09)

- Added the MIT license, an **About** dialog and a check for updates at startup.

## 1.0.0 (2026-11-09)

- First release: FTP and SFTP file transfers with native Windows shell icons, plus an installer.
